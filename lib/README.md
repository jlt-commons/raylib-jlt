# net.b12n.raylib

Hand-written [jolt](https://github.com/jolt-lang/jolt) bindings for
[raylib](https://www.raylib.com) 6.0, called directly over its C ABI through
`jolt.ffi`. No wrapper library, no codegen, no C shim.

## Using it

From another jolt project, while this lives inside the raylib-jlt repository:

```clojure
{:deps {net.b12n/raylib {:local/root "../raylib-jlt/lib"}}}
```

`:jolt/native` for `libraylib` is declared here and inherited by whatever
depends on this, so a consumer does not restate the Homebrew path. You still
need the library itself installed: `brew install raylib` on macOS, or your
distribution's raylib package.

## The modules

`net.b12n.raylib.all` re-exports everything, which is the convenient door:

```clojure
(:require [net.b12n.raylib.all :as rl])
```

Require a module directly when you want a narrow slice. `color` and `native`
sit at the bottom of the dependency graph, `kwargs` at the top.

`all.clj` is generated by `bb gen:all` and checked by `bb check:aggregator`.
Never edit it by hand.

- `color` — the packed `Color` uint32 and raylib's named palette.

## Checking it

```
bb check    # every namespace loads, headless, no window
bb lint     # clj-kondo
bb test     # the ffi/write argument-order suite
```
